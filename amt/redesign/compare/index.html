Method

Lighthouse 13.5.0 was run with Chrome headless (--headless=new --no-sandbox --disable-gpu). Mobile runs use Lighthouse’s default mobile emulation and simulated throttling. Desktop runs use --preset=desktop. Categories: performance, accessibility, best practices, SEO. The page reports the median. With an even number of successful runs the median is the mean of the two middle values. Scores are stored as Lighthouse’s 0–1 values and shown rounded to the nearest integer. LCP, CLS, TBT and total byte weight are the audit numericValue fields.

Each URL was run three times. This build read 174 run files: 159 returned a catalogue document, 15 were flagged blocked (HTTP status ≥ 400 or an error/challenge URL), 0 failed before a report. A blocked or failed run contributes no number. Image payloads and audit item lists were removed from the stored JSON; scores, numeric values, the main-document status and the Lighthouse metadata were copied across. The trim note is inside each file.
