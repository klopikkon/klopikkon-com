Move this onto AMT WordPress

AMT is a normal WordPress site (wp-content/uploads/… PDFs). This mockup is plain HTML on purpose so it pastes.

  1. Open wordpress-block.html and copy everything inside the page.
  2. On amtechpl.com: Pages → Add New. Title Price list. Slug price-list.
  3. In the Gutenberg editor, add a Custom HTML block. Paste. Publish.
  4. Appearance → Menus: add the page next to Catalogue / Brochures.
  5. Replace each homepage featured card so the dollars match this table. Do not keep two numbers for the same SKU.

No plugin required. If they later want staff to edit rows without HTML, import the same table into TablePress — the columns already match.
